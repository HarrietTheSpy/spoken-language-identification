# Data

This directory contains information about the datasets used in the project.

The raw Mozilla Common Voice audio files are not stored in this repository because of dataset size.

Project data preparation includes:

- Downloading language-specific speech samples
- Filtering unusable or corrupted audio files
- Converting audio to 16 kHz
- Converting recordings to mono
- Organizing samples by language
- Preparing data for MFCC feature extraction

The project uses speech samples from:

- English
- Spanish
- Mandarin Chinese
- Arabic
- Tamil
- Japanese
